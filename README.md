# 정산 승률 분석기

특정 커뮤니티 포인트 예측 게시판의 '정산' 글들을 자동으로 읽어서 참가자별 승률(종합/종목별)을 집계해주는 Tampermonkey 유저스크립트입니다.

## 설치

1. [Tampermonkey](https://www.tampermonkey.net/) 확장 프로그램을 설치합니다.
2. [`fmkorea_jungsan_analyzer.user.js`](https://raw.githubusercontent.com/srleeinkorea/rota-status/main/fmkorea_jungsan_analyzer.user.js) 링크를 클릭하면 Tampermonkey 설치 화면이 뜹니다. "설치"를 누르면 끝입니다.

설치 후에는 이 저장소에 새 버전이 올라올 때마다 Tampermonkey가 자동으로(또는 대시보드에서 "업데이트 확인"을 눌렀을 때) 최신 버전을 받아옵니다 — 매번 파일을 새로 받아서 수동으로 붙여넣을 필요가 없습니다.

## 사용법

- 해당 게시판의 **마감 탭** 또는 **진행중인 경기** 페이지를 열면 우측에 패널이 자동으로 뜹니다.
- 기간(오늘/24시간/2~30일)과 최소 베팅건수를 고른 뒤 "분석 시작"을 누르면 종합/종목별 승률 랭킹을 보여줍니다.
- 패널은 드래그로 위치를, 우하단 모서리로 크기를 조절할 수 있습니다.
- 종합 랭킹의 "진행중인 베팅" 컬럼은 아직 결과가 안 나온 경기에 그 사람이 어느 팀에(얼마를) 걸었는지 보여주며, 클릭하면 해당 경기 글로 이동합니다.

## 주요 특징

- 사이트 내부 AJAX를 직접 호출해서 글을 일일이 열어볼 필요가 없습니다.
- 정산 완료된 글의 결과는 영구 캐시되어, 기간을 바꿔가며 재분석해도 이미 받은 글은 즉시 재사용됩니다.
- 동시 요청 수를 적게 유지하고 요청 간격에 무작위성을 섞어서 사이트 보안 시스템에 걸리지 않도록 설계했습니다.
- 다른 스크립트가 페이지를 자동 새로고침해도 분석 진행 상태와 스크롤 위치가 유지됩니다.

## 주의

- 개인용 분석 도구입니다. 과도하게 공격적인 설정으로 바꾸면 사이트의 비정상 접속 탐지에 걸려 일시 차단될 수 있습니다.
- 사이트 구조(HTML/AJAX 응답 형식)가 바뀌면 동작하지 않을 수 있습니다.
